# incitaciones

> A curated library of reusable prompts and skills for CLI LLM tools (Claude Code, Amp, Gemini CLI, Cursor, Windsurf, Zed, pi).

## What It Does

incitaciones distills proven agent workflows — review passes, session
lifecycles, planning and debugging methods — into self-contained skills that
any coding agent can load on trigger. Each skill is a `SKILL.md` with
frontmatter (name, description, install provenance) plus distilled content;
compiled aliases serve legacy entry points.

- **47 skills** — review, session, planning, TDD, debugging, research,
  documentation, journaling, and more
- **Distillation pipeline** — source methods are distilled to
  token-efficient form and verified to preserve essential instructions
- **Multi-tool installs** — one manifest, many agents
- **Registry** — published to npm and GitHub Pages with a version-stamped
  catalog

## Installation

```bash
npx skills add incitaciones                     # skills.sh — works with any agent
pi install npm:incitaciones                     # pi
npx incitaciones install                        # all tools
npx skills add incitaciones --skill <name>      # per skill
```
