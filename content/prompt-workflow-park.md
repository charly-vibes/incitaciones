# Park Session

Snapshot current work before switching context. Logs to daily journal, releases ticket claims, records to `~/.whisper/`. This is NOT end-of-day — just a context switch.

## When to Use

- When switching to a different project mid-session
- When you need to pause work and come back later

See `content/distilled/park/SKILL.md` for the full procedure.
