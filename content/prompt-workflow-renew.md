# Renew Session

Resume work on a project or area. Loads context from journal, `~/.whisper/`, and beads. Supports claiming work with file conflict detection.

## When to Use

- When starting a new work session on a project
- When resuming work after a park or close
- When picking up a ticket from the issue tracker

See `content/distilled/renew/SKILL.md` for the full procedure.
